End-to-End Execution Flow
STEP 1 User writes / uploads Gherkin
in BDDTesting.tsx
→
STEP 2 POST /api/bdd/parse
Preview parse (no save)
→
STEP 3 POST /api/bdd/features
Persist Feature + Scenarios + Steps
→
STEP 4 POST /api/bdd/features/:id/run
Trigger execution
→
STEP 5 BDD Service generates
Playwright TS code
→
STEP 6 Spawn Playwright subprocess
(chromium/firefox/webkit)
→
STEP 7 SSE stream → live step
results to frontend
→
STEP 8 Generate Allure +
Serenity reports
→
STEP 9 Persist BDDRun record
with all step results
→
STEP 10 GET /api/bdd/runs/:id/report
View HTML report

EXTRACT Parse acceptance

AI GEN OpenAI generates

→
CONVERT workflowOrchestrator

generated scenarios

REPORT Serenity + Allure
